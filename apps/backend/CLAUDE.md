# apps/backend — CLAUDE.md

FastAPI + PostGIS service. Owns all data, geometry, raster, and external-provider
access behind an authenticated `/api/v1`. The agent and UI never touch the DB or
provider keys directly — they go through these endpoints.

> Big picture: `../../CONTEXT.md`. CI gate commands: root `../../CLAUDE.md`
> (`ruff format --check`, `ruff check`, `mypy` advisory, `pytest`, + the Alembic
> migrations smoke job). `mypy` is advisory; the shapely-stub errors are
> pre-existing.

Stack: FastAPI · Pydantic v2 · SQLAlchemy 2.0 async (asyncpg) · GeoAlchemy2 ·
Alembic · uv · Python 3.12.

## Request flow / layers

```
api/v1/routes/*   thin HTTP handlers (validation, status codes, auth dep)
   → services/*   orchestration / business logic
   → repositories/*  DB access (SQLAlchemy)
   → models/*     ORM models (GeoAlchemy2 geometry columns)
```

Cross-cutting:

- `geo/` — geometry, raster, and provider helpers: `operations.py` (PostGIS
  buffer/distance/area/intersects/within), `indices.py` (band math for the eight
  spectral indices), `collections.py` (per-sensor band aliases + scaling),
  `masking.py` (per-pixel cloud/shadow masks: S2 SCL classes, Landsat QA_PIXEL
  bits), `raster.py` (rasterio/GDAL COG reads via `/vsicurl` + zonal stats),
  `cube.py` + `reducers.py` (multi-date cube and its per-pixel reductions),
  `phenology.py` (season-shape metrics + baseline anomaly), `stac.py` (Earth
  Search over httpx).

  **Masking is not optional in the read paths.** Both `raster.zonal_stats` and
  `cube.build_reduction` apply the collection's `MaskSpec` before any statistic
  is computed; unmasked cloud biases means low and inflates temporal CV into
  fake instability. A change to that math needs a `_STAT_CACHE_VERSION` bump
  (`services/raster_service.py`) and/or a `recipe_version` bump
  (`schemas/artifact.py`), or stale results keep being served.
- `schemas/` — Pydantic v2 request/response models.
- `core/` — `security.py` (JWT encode/decode), `errors.py`, `logging.py`.
- `db/` — engine/session.
- `api/deps.py` — `DbSession`, `get_current_user`/`CurrentUser` (HTTPBearer →
  decode JWT → load active user).
- `config.py` — `Settings` (pydantic-settings); env via `.env` / `.env.example`.

## Conventions & invariants

- **Auth-gate everything under `/api/v1`** except health, `auth/login`, and the
  intentionally public `GET /features` read (the agent enumerates features
  without a token; `POST /features` still requires `CurrentUser`). Use
  `Depends(get_current_user)` (per-route or router-level, e.g.
  `APIRouter(dependencies=[Depends(get_current_user)])`). A new router that
  forgets this is a security bug — mirror `routes/raster.py`.
- **Keep routes thin.** Logic lives in `services/` (DB-backed) or `geo/`
  (geometry/providers). Routes map inputs → call → response/status.
- **External calls go through a `geo/` provider module** (`httpx`, mirror
  `stac.py`): explicit timeout from settings, a typed error class (`StacError`),
  response normalization. Map provider failure to an `HTTPException` in the
  route — convention: **502** upstream failure, **503** when a provider is
  unconfigured.
- **SSRF guard:** validate any caller-supplied value that becomes a URL path
  segment (`stac.py:_safe_segment`).
- **Validate at the schema, not downstream.** Use Pydantic v2 constraints
  (`ge`/`le`/`gt`, `min_length`, element-level `Field(gt=0)`) so bad input is a
  **422**, not a 5xx from a provider/DB.
- **Settings:** add provider URLs/keys to `config.py` + `.env.example`. The
  weak-JWT-secret validator rejects dev defaults when `APP_ENV != development`.

## Testing (no live network or DB)

- Shared `client` fixture (`tests/conftest.py`): `ASGITransport` over the app
  with `get_current_user` overridden to a stub user, so behaviour tests skip
  JWTs.
- **Unit tests monkeypatch the service or geo layer** —
  `monkeypatch.setattr(routes.X.Service, "method", fake)` (see
  `test_fields.py`, `test_raster_time_series.py`) or, for provider modules,
  drive `httpx` via `httpx.MockTransport` (mirror `tests/geo/test_indices.py`
  style unit tests). When a provider test changes env, call
  `get_settings.cache_clear()`.
- **Auth-boundary tests** strip the override (pop `get_current_user`) to
  exercise the bearer guard — expect **403** (missing header) or **401**
  (invalid token). See `test_*_auth.py`.
- No real PostGIS in unit tests. The CI **migrations smoke job** runs
  `alembic upgrade head` against `postgis/postgis:16-3.4` — keep autogenerated
  revisions runnable (`make revision m=...`, `make migrate`).

## Adding a capability (typical shape)

1. `geo/<provider>.py` or `services/<x>.py` for the logic (+ typed error).
2. `schemas/<x>.py` Pydantic v2 request/response.
3. `api/v1/routes/<x>.py` — auth-gated router; map errors → HTTPException.
4. Register in `api/v1/router.py`.
5. Tests: route behaviour (provider/service monkeypatched), an auth-boundary
   test, and provider-layer tests via `MockTransport`.
